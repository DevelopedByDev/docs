Notes give you a dedicated writing space inside Overlay — separate from chat, but connected to the same context layer. Use notes for drafting, outlining, meeting records, research summaries, or any structured writing that you want to keep alongside your conversations and files. Notes autosave as you type, support rich text formatting, and can be linked to projects so they stay organized with the rest of your work.

## Creating a note

<Steps>
  <Step title="Open Notes">
    Click **Notes** in the left sidebar.
  </Step>
  <Step title="Create a new note">
    Click **+ New note**. A blank editor opens immediately.
  </Step>
  <Step title="Add a title">
    Click the title area at the top and type a title. The title is used for organizing and searching your notes.
  </Step>
  <Step title="Start writing">
    Click into the editor body and begin typing. Your note saves automatically as you write.
  </Step>
</Steps>

## Rich text formatting

The editor supports a full set of formatting options. Use the toolbar at the top of the editor or trigger formatting with slash commands (see below).

| Format | What it does |
|---|---|
| **Heading 1 / 2 / 3** | Section headers at different levels |
| **Bold / Italic** | Inline emphasis |
| **Bulleted list** | Unordered list items |
| **Numbered list** | Ordered list items |
| **Quote** | Block quotation styling |
| **Code block** | Monospace code with language highlighting |
| **Divider** | Horizontal rule to separate sections |

## Slash commands

Type `/` anywhere in the editor body to open the command menu. Select a block type to insert it at your cursor position.

<Tip>
  Slash commands are the fastest way to insert structured content like code blocks, headings, or callout sections without reaching for the toolbar.
</Tip>

Common slash commands include:

- `/heading1`, `/heading2`, `/heading3` — insert a heading
- `/bullet` — start a bulleted list
- `/numbered` — start a numbered list
- `/code` — insert a code block
- `/quote` — insert a block quote
- `/divider` — insert a horizontal rule

## Autosave

Notes save automatically every few seconds and whenever you pause typing. You do not need to press a save button. If you navigate away from a note and return, your content will be exactly as you left it.

## Tagging notes

Add tags to your notes to make them easier to find and filter. Tags appear in the note list and can be used to group related notes across projects.

<Steps>
  <Step title="Open the note options">
    Click the tag icon or the options menu (⋯) in the note header.
  </Step>
  <Step title="Add tags">
    Type a tag name and press Enter to add it. Add as many tags as you need.
  </Step>
  <Step title="Filter by tag">
    In the Notes list view, click a tag to filter and show only notes with that tag.
  </Step>
</Steps>

## Linking notes to projects

Notes can be attached to a project so they appear alongside that project's chats and files.

<Tabs>
  <Tab title="When creating a note">
    Open the project first, then click **+ New note** from within the project view. The note is automatically linked to that project.
  </Tab>
  <Tab title="From an existing note">
    Open the note, click the options menu (⋯), and select **Move to project**. Choose the project from the list.
  </Tab>
</Tabs>

Project-linked notes appear in the project's sidebar and are also available as context when you chat inside that project.

## Using AI to edit notes

Overlay can use AI to help you draft, refine, or expand a note.

<Steps>
  <Step title="Open the note you want to edit">
    Navigate to the note in the Notes view.
  </Step>
  <Step title="Select the text you want to work with">
    Highlight a passage, or leave nothing selected to work with the entire note.
  </Step>
  <Step title="Open the AI editing menu">
    Click the AI edit button (sparkle icon) that appears in the toolbar when text is selected, or use the slash command menu to insert an AI block.
  </Step>
  <Step title="Give an instruction">
    Type what you want: "make this more concise," "add a section on risks," "rewrite in a formal tone." The AI applies the edit to your note.
  </Step>
</Steps>

<Info>
  AI edits in notes use the same model you have selected in chat. Switch to a more capable model if you want higher-quality rewrites.
</Info>

## Frequently asked questions

<AccordionGroup>
  <Accordion title="Can I use markdown syntax directly in notes?">
    Yes. The editor recognizes common markdown shortcuts as you type. For example, typing `##` followed by a space converts the line to a heading, and typing `-` followed by a space starts a bulleted list.
  </Accordion>
  <Accordion title="Can I export a note?">
    You can copy the full text of any note to your clipboard. Export options (PDF, markdown file) may vary by plan.
  </Accordion>
  <Accordion title="Is there a character or size limit for notes?">
    Notes support up to 200 entries in your account. Individual note size is generous for everyday writing; very large documents are better suited to the Knowledge base.
  </Accordion>
  <Accordion title="How do notes relate to the Knowledge base?">
    Notes are a writing surface. Knowledge is an indexed document store. You can move or copy note content into the Knowledge base if you want it to be retrievable in chat. Notes linked to a project are available as context within that project automatically.
  </Accordion>
</AccordionGroup>
